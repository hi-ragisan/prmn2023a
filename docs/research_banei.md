# ばんえい競馬（帯広）実態調査 — コードの前提との照合

- 調査日: 2026-11-02（レーン L1 research）
- 目的: `banei_ai/` が置いている前提（払戻率・場コード・水分・負担重量・頭数・人気馬の成績・売上規模など）を、実在の情報源で確認する。

## 調査方法と信頼度の表記

- この環境のシェル（curl/requests）からは競馬サイトに届かず、WebFetch も oddspark.com・hokkaido-np.co.jp では名前解決エラーで取得できなかった。
  そのため、**ほぼすべての事実は Web 検索結果の要約（検索エンジンが出典ページから抜き出した記述）経由**で確認している。原文ページを直接開いて照合したものではない。
- 表記:
  - **確認済み（URL）** … 出典ページの記述を検索結果で確認できたもの。公式（帯広市・ばんえい十勝・NAR・JRA）か準公式（オッズパーク、楽天競馬などの発売・データ提供元）。
  - **確認済み・二次（URL）** … 個人ブログ・まとめサイトなど、公式ではない出典。
  - **推定** … 上記の数値から筆者（L1）が計算・推論したもの。計算過程を併記する。
  - **未確認** … 出典を見つけられなかったもの。一般知識による見込みを書く場合もそう明記する。
- L2（スクレイパー）レーンが GitHub 上の公開コードから得た情報は「L2 報告」と明記して引用している。

### 単勝プールの推定（L3 の市場インパクト用）

- **単勝プール ≈ 1レース 250万円（推定。通常のレースでおよそ 100万〜500万円）**。
  根拠: 1レースの全券種 3,300〜3,500万円 × 単勝の構成比 7〜8% ≈ 230〜280万円。GW・最終日の実例（200万〜480万円）とも矛盾しない。
  早い時間のレースは少なく、最終レース・祝日・重賞は多いと見込まれる（**未確認**）。トップ重賞は 1,000〜1,200万円。
- 複勝プール ≈ 単勝の 0.85 倍（上の実例より、推定）。
- 自分の購入が配当に与える影響（推定）: プール 250万円で、オッズ 20倍の馬（その馬への票は約 10万円）に 1万円賭けると、配当はおよそ 18.3倍まで下がる（−8〜9%）。オッズ 10倍なら −4〜5%、オッズ 5倍なら −2% 程度。1,000円の購入ならほぼ無視できる（−1% 未満）。
- 時系列オッズは [keibaodds.com/nar](https://keibaodds.com/nar) に帯広を含む地方競馬の掲載がある（どの期間まで遡れるかは**未確認**）。

## Q4. 馬場水分

- **公表形式**: 馬場の状態を良・稍重などの言葉ではなく、**水分のパーセント（小数第1位）**で示す（[オッズパーク ばんえい予想入門](https://www.oddspark.com/club/keiba/beginner/banei_yosou_3min.html)、確認済み）。
  - netkeiba の結果ページの見出し部分は「**天候:晴 / 水分量:1.6**」の形で、**% 記号が付かない**（検索結果の抜粋で確認。例 race_id=202465101409「18:55発走 / 直200m / 天候:晴 / 水分量:1.6」）。
  - keiba.go.jp の当日メニュー（RaceList）は「曇 | 2.4」のように、馬場の列に数字だけが入る（L2 報告とも一致）。
  - 楽天競馬は「ダ：2.7%」のように % を付けて表示する。
- **用語が平地と逆**: 水分が多い＝「**軽馬場**」（ソリが滑ってタイムが速い）、乾燥＝「**重馬場**」（力の要る馬場でタイムがかかる）（オッズパーク・[ばんえい猫のアルル](https://banei-neko.hatenablog.jp/entry/2021/07/25/083014)、確認済み・二次を含む）。
- **範囲**: 通常 0.1〜9.9%、積雪時などは 10% を超えることもある（ばんえい猫のアルル、確認済み・二次）。[pluskeiba](https://pluskeiba.com/course/obihiro/) は 0.0〜9.9%。日本語版 Wikipedia「馬場状態」は「含水率 2.0〜3.0% が標準」とする。2.5% を超えると速い馬場という目安を書く記事もある。
- **タイムへの影響**: 水分が高いほど速い。ただし水分が高すぎると、重い重量のレースではソリが馬場に吸い付いてかえって時計がかかる、という指摘もある（[うまめし](https://www.umameshi.com/info/keibajou/ばんえい競馬必勝法.html)、確認済み・二次）。「水分 1% あたり何秒」という定量的な換算は**未確認**。通常の走破タイムは 2 分前後（例: ばんえい菊花賞は水分 1.6% で 2分16秒9）。
- **季節ごとの実測例**（検索で拾えたレース単位の値。n≈12 なので**参考程度**）:

| 時期 | 値 | 出典 |
|---|---|---|
| 夏 | 0.4%（2025-07-13・晴）、0.8（2023-07 ばんえい大賞典・晴）、2.2（2025-08 ばんえいグランプリ・小雨） | 楽天競馬 競走成績・netkeiba |
| 秋 | 1.6（2024-10-14・晴）、1.0%（2026-10-17・曇）、1.6（ばんえい菊花賞） | netkeiba・楽天競馬 |
| 冬 | 2.7（2025-12-30）、2.3（2026-01-02 帯広記念）、2.7%（2026-01-09）、2.4（2026-01-19・曇）、1.3（2025-03-16 ばんえい記念・雪）、3.8（2026-03-07） | netkeiba・楽天競馬・keiba.go.jp |

  ⇒ 夏はおよそ 0.4〜2%（雨の日は上がる）、冬はおよそ 1.3〜3.8%。冬が高めという傾向はあるが、シミュレーターの冬平均 3.5% はやや高い可能性がある（**低い信頼度**）。

## Q5. 負担重量（ばんえい重量）

- 公式の呼び名は「**ばんえい重量**」（ソリと重りの重量。騎手の体重は含まない）。
- **基礎重量はクラス別で、開催回が進むほど重くなる**: 2022年度第14回の番組の表では、第1〜3回が オープン 660kg・A1 650kg・…・B4 600kg・C1 580kg・C2 570kg。開催回が進むと 10kg 刻みで重くなり、第25回にはオープン 740kg・A1 730kg（[帯広市ばんえい競馬番組 2022年度第14回](https://www.banei-keiba.or.jp/race_program_detail.php?d=2022&n=14)、確認済み）。
  A2〜B3 の値は抜粋に出ていなかった。A1 と B4 の差が 50kg なので、10kg 刻みで A2 640・B1 630・B2 620・B3 610 と**推定**。2024年度の番組でも重量の水準は同じ（区分の賞金額だけ変わっている）。
- **加増**: 公式番組（2024年度第2回）では、3歳以上の馬は本年度の収得賞金 230万円ごとに 5kg 加増、2歳馬は 210万円ごとに 5kg 加増とある（[帯広市ばんえい競馬番組 2024年度第2回](https://www.banei-keiba.or.jp/race_program_detail.php?d=2024&n=2)、確認済み。対象クラスの条件が抜粋では読み切れなかった）。
- **牝馬は 20kg 減**: 「2歳以上7歳以下の牝馬は 20kg 減量」。牝馬限定戦にも適用される（同上、確認済み）。
- **2歳**: 5月のデビュー時は 480kg（牝馬は 460kg）で、翌年3月には 550〜580kg まで増える（[北海道Likers](https://hokkaidolikers.com/archives/48429)、[ニコニコ大百科](https://dic.nicovideo.jp/a/%E3%81%B0%E3%82%93%E3%81%88%E3%81%84%E7%AB%B6%E9%A6%AC)、確認済み・二次）。
- **重賞**: ばんえい記念は唯一の 1,000kg（牝馬 −20kg、5歳以下 −10kg）（[ばんえい十勝 ばんえい記念](https://banei-keiba.or.jp/race_grade_detail.php?id=121)・ニコニコ大百科、確認済み）。重賞の条件は「3歳オープン別定」のように**別定**が多い（例: [keiba.go.jp ばんえい菊花賞の出馬表](https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/DebaTable?k_raceDate=2024%2F11%2F03&k_babaCode=3&k_raceNo=11)）。特別戦は基礎重量に 20〜30kg 上乗せするとの記述もある（確認済み・二次）。
- **騎手の減量**: 通算 50 勝未満の騎手などは **10kg 減で、出馬表では「☆」**。免許取得から5年以内で通算 50〜100 勝の騎手は、その年度の 10 勝目まで減量（[オッズパーク コラム 2023-01](https://sp.oddspark.com/keiba/blog/saito/2023/01/20.html)、確認済み）。**女性騎手はさらに 10kg 減**で、新人の女性騎手は計 20kg 減になりうる（同コラム）。女性騎手の減量の記号は**未確認**。
  `norm_name` が取り除く記号（☆▲△★◇）に ☆ が含まれているので、名前の正規化はこのままで問題ない。
- 実際の重量の例: 一般戦の出馬表で 660〜685kg（競馬ブック・keiba.go.jp の出馬表の抜粋）。netkeiba は「1000.0」のように小数付きで表示する。
- 馬体重: 800〜1,200kg（[nippon.com](https://www.nippon.com/ja/column/g00590/)、確認済み・二次）。「1トン前後」とする情報源も多い。

## Q6. クラス体系と複勝のルール

- **格付けは通算収得賞金（3年度前の年度初めから数えた額）による**。2025年度第1回の番組（[帯広市ばんえい競馬番組 2025年度第1回](https://www.banei-keiba.or.jp/race_program_detail.php?d=2025&n=1)、確認済み）:
  - 5歳以上の馬と、3・4歳で 340万円以上の馬: オープン（1,300万円以上）、A1（1,300万円未満）、A2（1,000万円未満）、B1（850万円未満）、B2（670万円未満）、B3（550万円未満）、B4（430万円未満）。
  - 3・4歳で 340万円未満の馬: C1（340万円未満）、C2（220万円未満）。
  - 2歳馬は本年度の収得賞金の順に格付けする。
  - 境界の金額は年度・開催回によって変わる（例: 2024年度第16回は B4 330万円未満・B1 750万円未満、古い要領では C1 240万円・C2 140万円）。
- レース名は「C1ー5」のように、クラスの後ろに組番号が付く（netkeiba race_id 202565031001 の見出し）。`find_race_class` の正規表現（`C1` の直後が数字でなければ一致）は「C1ー5」「B1−」の形に一致する。
- 最新の格付けは公式の[競走馬格付けデータ](https://www.banei-keiba.or.jp/db_rating.php)で確認できる。
- **複勝**: ばんえい公式の説明は「3着までに入る馬を当てる。**出走頭数が7頭以下の場合は2着まで**」（[ばんえい十勝 ガイドブック p58-59](https://banei-keiba.or.jp/dl/pdf/ebook/10th_thebanba/p058_059.pdf)、確認済み）。
  - **4頭以下は発売しない**ことと、**頭数は発売開始時の出走予定頭数で決まり、発売後に取消があっても変わらない**ことは、JRA のルールで確認済み（[JRA 馬券のルール](https://www.jra.go.jp/kouza/baken/index.html)）。地方・ばんえいの規程で同じかどうかは**未確認**（同じである見込みが高い）。

## Q7. 場コード

- **netkeiba の race_id = YYYY + 65 + MMDD + RR**: **確認済み**（実在する URL が多数ある）。
  - 202565031001「C1ー5」（2025-03-10 1R）、202465070711 ばんえい大賞典（2024-07-07 11R）、202465081111 ばんえいグランプリ（2024-08-11 11R）、202565031612 ばんえい記念（2025-03-16 12R）、202465123011 ばんえいダービー（2024-12-30 11R）、202665010208 帯広記念（2026-01-02 8R）。

  - netkeiba のばんえいの馬 ID は「B」で始まる（例: `db.netkeiba.com/horse/result/B201900123/`）。数値だけの ID を前提にしないこと。
- **keiba.go.jp の k_babaCode = 3**: **確認済み**。[出馬表のページ](https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/DebaTable?k_raceDate=2026%2F05%2F25&k_raceNo=11&k_babaCode=3)のタイトルが「2026年5月25日（月） 帯 広 第11競走 20:05発走」。「帯 広」のように文字の間に空白が入っている点に注意。

  - 参考: オッズパークは `opTrackCd=03`、楽天競馬の RACEID も場コード `03`。

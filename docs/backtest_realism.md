# バックテストの現実性: 小さな単勝プールに実際に賭けたらどうなるか

ふつうのバックテスト（`data/reports/backtest.md` の前半）は次の2つを無視しているので、回収率は**上限の目安**です。

1. **自分の購入でオッズが下がる**: 単勝はパリミュチュエル（売上を払戻率で山分け）。ばんえいは売上が小さいので、
   数千円〜数万円の購入でも自分の買った馬のオッズが目に見えて下がる。
2. **買う時点のオッズと確定オッズは違う**: 判断は締切前のオッズで行い、払戻は確定オッズで受け取る。

`python -m banei_ai.cli backtest` の最後の節「現実性」は、この2つを入れたときに回収率がどこまで下がるか、
**1点いくらまでなら歪み（エッジ）が残るか**を計算します。

```bash
python -m banei_ai.cli backtest --pool-yen 2500000 --odds-noise 0.1     # 既定: --pool-yen 2500000 --odds-noise 0
python -m banei_ai.cli backtest --preds data/reports/walkforward_preds.pkl  # 保存済みの予測を使い、学習を省略
python -m banei_ai.cli backtest --pool-yen 0 --odds-noise 0                 # 影響なし = 従来どおり
```

| オプション | 意味 |
|---|---|
| `--pool-yen` | 1レースの単勝売上 T（円）の仮定。0 = 自分の購入の影響なし |
| `--odds-noise` | 締切前オッズのズレの大きさ σ。0 = 確定オッズで判断（従来どおり） |
| `--payout-rate` | 単勝の払戻率 R（既定 0.80） |
| `--noise-reps` | σ>0 のときの抽選回数（既定 5。平均を表示） |
| `--preds` | 保存済みのウォークフォワード予測を読み込んで学習を省略 |

前半の既存の節は `--pool-yen` / `--odds-noise` の影響を受けません（数値はこれまでと同じ）。

---

## 1. 方法

### 1.1 自分の購入によるオッズ低下（`backtest.impact_odds`）

単勝の総売上を T、払戻率を R、馬 i に入っている票を W_i とすると、確定オッズは o_i = R·T / W_i。
自分がその馬に s_i 円を足すと（同じレースで買った自分の馬券はすべて総売上に入る）:

```
o_i' = floor_0.1( R·(T + Σ_j s_j) / (W_i + s_i) )   (最低 1.0 = 元返し)
W_i  = R·T / (o_i + 0.05)
```

- 払戻は 10 円未満切り捨てなので、表示オッズ o_i の真の値は [o_i, o_i+0.1) のどこか。中点 o_i + 0.05 を使う
  （o_i そのものを使うと、100 円買っただけで必ず 0.1 下がるという偏りが出る）。s=0 なら o_i を正確に再現する。
- 自分の影響は **s / T（またはその馬の票 W_i に対する s）だけで決まる**。プールが 2 倍なら同じ影響の賭け金も 2 倍。
- 均等買い `flat_bet(bets, stake, pool_yen=T)`、分数ケリー `kelly_bet(bets, pool_yen=T)` に組み込み済み。
  ケリーは資金に比例して賭けるので、**資金が増えるほど影響が大きくなる**。
- 既定（`pool_yen=0`）では従来と完全に同じ結果（テストで確認）。

1点だけ買うときの理論値（`backtest.optimal_stake`、切り捨ては無視）:

```
損益分岐の賭け金  s* = (p·R·T − W) / (1 − p·R) = W·(EV − 1) / (1 − p·R)
利益最大の賭け金  s_opt = W·(√(1 + s*/W) − 1) ≈ s*/2
```

EV は自分が買う前のオッズでの期待値 p×o。**利益最大の賭け金 ≈ (EV − 1)/2 × その馬に入っている票** が覚えやすい目安です。

### 1.2 締切前オッズのズレ（`backtest.preclose_view`）

```
締切前オッズ õ_i = o_i × exp(ε_i),  ε_i ~ N(0, σ)  (馬ごとに独立)
```

その後レース内で Σ 1/õ_i = Σ 1/o_i（= 1/払戻率、控除込みの合計）になるよう正規化し直します。
判断（市場確率・AI勝率・期待値・ケリー額）は締切前オッズで、払戻は確定オッズ（＋自分の影響）で計算します。

**AI勝率も締切前オッズで計算し直す**のが正直な判断です。Stage2 は条件付きロジットなので

```
u_i = log p_model_i + b·(log p̃_mkt_i − log p_mkt_i)   → レース内 softmax
```

が「Stage2 に締切前の市場確率を入れて予測し直した値」と厳密に一致します（b = Stage2 の log 市場確率の係数, 生の単位）。

- b はブロック（2か月）ごとに違う。`walk_forward` の出力には Stage2 の学習に使われた最初の 2 ブロックが
  含まれないため、出力から Stage2 を学習し直しても同じモデルは作れない。そこで `stage2_market_coef` は、
  条件付きロジットでは同じレース内で log p_model_i − log p_model_j = Σ_k β_k (x_ik − x_jk) が厳密に成り立つことを使い、
  レース内で中心化した最小二乗で β を**予測値から逆算**します（欠損は Stage2 と同じく平均補完なので欠損ダミーを追加）。
- シミュレーションでの復元誤差は p_model で最大 1e-15。σ=0 で p_model を 1e-12 以内で再現。
  テストでは本物の `Stage2` を学習させ、(a) 係数が一致、(b) 市場確率を差し替えた予測が Stage2 の再予測と 1e-9 以内で一致することを確認。
- `model.py`（Stage2 の形）が変わって効用が `s1, log_p_mkt, j_popularity, h_last_pmkt_share` の線形でなくなった場合、
  レポートの「復元誤差」が大きくなるので分かります（その場合 b は線形近似）。

### 1.3 感度分析（レポートの「現実性」節）

| 関数 | 内容 |
|---|---|
| `robustness_table(P, rule=...)` | プール × σ × 1点の賭け金 ごとの均等買いの点数・的中率・回収率・90%区間・収支・払戻オッズ比 |
| `breakeven_table(P, rule=...)` | プール × σ ごとの「損益分岐の賭け金」「利益最大の賭け金」（100 円単位、二分探索） |
| `kelly_robustness(P, rule=...)` | 1/4ケリーの資金推移（初期資金 10 万・100 万円、1点上限 = プールの 1% の場合も） |
| `optimal_stake(p, odds, pool_yen)` | 1点の理論値（上の式） |

σ>0 は 5 回の抽選の平均。乱数は σ 間で共通（ε = σ·z）なので σ 同士の比較がぶれにくい。
90% 区間はレース単位のブートストラップ（従来の `bootstrap_roi` と同じ手順。プール 0・σ 0・100 円の行は従来の値と一致）。

## 2. 前提値（実データの値が必要なもの）

| 値 | 既定 | 根拠・確度 |
|---|---|---|
| 単勝の払戻率 R | 80% | 地方競馬の単勝・複勝は 2014-04 以降 80%（確度: 高） |
| 1レースの単勝売上 T | **250 万円** | 帯広の年間売上 ≈ 550 億円（2022〜2025 年度）÷ 約 1,650 レース ≈ 3,300 万円/レース（全券種）。単勝のシェアは実例（2026-03-22 8R）で 7.8% → 約 250 万円。2026-05-04 の各レースの単勝は約 200〜480 万円、ばんえい記念 2024 は約 1,170 万円。**推定値（確度: 中）** |

- 実際の単勝売上は**レースごとに大きく違う**（早い時間の下級条件は 100 万円前後、最終レース・休日・重賞は数百万〜1,000 万円超）。
  ここでは全レース一定と仮定しています。レースごとの売上（票数）が取れるようになったら、`flat_bet` / `kelly_bet` の
  `pool_yen` に列名を渡せばレースごとの値を使えます（例: `pool_yen="win_pool_yen"`）。
- 締切前オッズのズレ σ の実際の大きさは未調査。時系列オッズ（例: keibaodds.com の地方競馬）で
  「購入する時刻のオッズ」と確定オッズの対数比の標準偏差を測れば σ を決められます。

## 3. 結果（**シミュレーションデータ**、実際のばんえい競馬の成績ではありません）

`simulate`（2023-04〜2025-09, seed 42）→ ウォークフォワード（評価 2024-06〜2025-09, 1,891 レース）、
購入ルール min_ev=1.10（767 点、確定オッズ・影響なしで回収率 1.250, 90% 区間 [1.125, 1.381]）。
このシミュレーションは市場に大きな歪みを埋め込んであり、**エッジは実際の市場よりずっと大きい**はずです。
数字そのものより「どう減るか」を見てください。

### 3.1 均等買いの回収率（σ=0, 確定オッズで判断）

| 単勝プール | 100円 | 1,000円 | 5,000円 | 10,000円 | 損益分岐の賭け金 | 利益最大の賭け金 |
|---|---:|---:|---:|---:|---:|---:|
| 影響なし | 1.250 | 1.250 | 1.250 | 1.250 | — | — |
| 50 万円 | 1.250 | 1.240 | 1.186 | 1.131 | 25,500 (5.1%) | 11,800 |
| 100 万円 | 1.250 | 1.246 | 1.219 | 1.186 | 50,900 (5.1%) | 21,900 |
| 250 万円 | 1.250 | 1.249 | 1.240 | 1.226 | 127,200 (5.1%) | 54,700 |
| 500 万円 | 1.250 | 1.250 | 1.246 | 1.240 | 254,400 (5.1%) | 110,700 |

- 1,000 円までは影響はほぼゼロ。250 万円のプールで 1 万円均等にすると回収率は 1.250 → 1.226（実際に受け取るオッズは約 2% 低い）。
- 損益分岐・利益最大の賭け金は**プールにほぼ比例**（このエッジでそれぞれプールの約 5%、約 2.2%）。
  利益最大はおおむね損益分岐の半分（1.1 節の式どおり）。

### 3.2 締切前オッズのズレ（プール 250 万円）

| σ | 点数 | 100円 | 10,000円 |
|---|---:|---:|---:|
| 0 | 767 | 1.250 | 1.226 |
| 0.05 | 767.8 | 1.243 | 1.220 |
| 0.10 | 767.4 | 1.241 | 1.217 |
| 0.20 | 762.6 | 1.242 | 1.218 |

- AI勝率を締切前オッズで**計算し直せば**、ズレの影響は小さい（回収率 −0.01 程度）。
  Stage2 の市場係数 b が 1.04〜1.18 と ≈1 なので、締切前オッズが高く見えると AI勝率もほぼ同じ割合で下がり、
  期待値 p×o はほとんど変わらない（期待値の変化は exp((1−b)·ε) 倍）。
- 一方、**前に計算した AI勝率に最新オッズを掛けて判断すると**（b=0 と同じ）、たまたまオッズが高く表示された馬ばかり買う逆選択が起きる:

| σ | 再計算する: 点数 / 回収率 | しない: 点数 / 回収率 |
|---|---:|---:|
| 0.05 | 767.8 / 1.243 | 823.6 / 1.188 |
| 0.10 | 767.4 / 1.241 | 1008.6 / 1.119 |
| 0.20 | 762.6 / 1.242 | 1611.4 / 1.008 |

### 3.3 1/4ケリー（1点上限 = 資金の 3%, σ=0）

| 初期資金 | プール | 1点上限 | 資金倍率 | 最大DD | 払戻オッズ比 |
|---|---|---|---:|---:|---:|
| 10 万円 | 影響なし | — | 14.4 | 35% | 1.000 |
| 10 万円 | 250 万円 | — | 12.0 | 36% | 0.980 |
| 10 万円 | 50 万円 | — | 6.8 | 37% | 0.934 |
| 100 万円 | 影響なし | — | 14.8 | 35% | 1.000 |
| 100 万円 | 250 万円 | — | 4.7 | 39% | 0.905 |
| 100 万円 | 50 万円 | — | 1.4 | 50% | 0.828 |
| 100 万円 | 50 万円 | 5,000 円 (プールの1%) | 1.7 | 9% | 0.951 |

- 影響がなければ資金倍率は初期資金によらない（14 倍前後）が、プールが有限だと**資金が大きいほど伸びない**。
  100 万円スタートで 50 万円プールなら 14.8 倍 → 1.4 倍。1 点が数万〜20 万円になると、実際に受け取るオッズは平均で 10〜17% 下がる。
- 1点の上限をプールの 1% にすると、小さいプールでは成績もドローダウンも改善する（大きいプールでは上限が効きすぎて少し下がる）。

## 4. ばんえいでの賭け金の目安（実践）

1. **1点の上限は「その馬に入っている票」で決める**: 利益最大 ≈ (EV − 1)/2 × W_i、W_i = 0.8 × 単勝売上 ÷ オッズ。
   単勝売上 250 万円のレースでの理論値（利益最大 / 損益分岐, 円）:

   | 単勝オッズ | その馬の票 | EV 1.05 | EV 1.10 | EV 1.20 |
   |---:|---:|---:|---:|---:|
   | 3.0 | 66.7 万円 | 22,760 / 46,296 | 45,610 / 94,340 | 91,729 / 196,078 |
   | 5.0 | 40 万円 | 11,844 / 24,038 | 23,577 / 48,544 | 46,771 / 99,010 |
   | 10.0 | 20 万円 | 5,386 / 10,917 | 10,680 / 21,930 | 21,019 / 44,248 |
   | 20.0 | 10 万円 | 2,576 / 5,219 | 5,100 / 10,460 | 10,004 / 21,008 |

   売上 100 万円のレースならこの 0.4 倍。**大穴ほど票が少ないので、同じ金額でもオッズが大きく下がる**。
   現実的なエッジ（EV 1.05〜1.10）の 10 倍の馬なら、1 万円は EV 1.10 で利益最大の額、EV 1.05 ではすでに損益分岐。
2. **期待値ぎりぎり（EV 1.1 前後）の馬は少額に**。損益分岐の賭け金は EV−1 に比例するので、エッジが半分なら上限も半分。
3. **ケリーの額をそのまま使わない**: 資金が増えたら「資金の何%」ではなく「プール（その馬の票）の何%」で頭打ちにする
   （`kelly_bet(..., max_stake=...)` / `kelly_robustness(..., max_stake_pct_pool=1.0)`）。
4. **締切直前に AI勝率ごと計算し直す**（`predict` を再実行）。古い AI勝率 × 新しいオッズで判断すると逆選択で回収率が大きく下がる。
5. 単勝の票数（売上）が見られる場合はそれで T を確認する。締切前の売上は締切までにまだ増えるので、
   締切前の値で計算すると影響を少し大きめに見積もる（安全側）。

## 5. 限界と今後

- **締切前オッズのズレは情報を含まない雑音として扱っている**。一般に締切直前に入る資金は勝ち馬についての情報を含むと言われ
  （直前に人気が上がる馬ほどよく勝つ）、その場合は「確定オッズで作ったモデル」が締切前に使える情報より良く見えるため、
  ここでの悪化より大きくなり得る。時系列オッズのデータが取れたら、締切 n 分前のオッズで Stage2 を学習・評価し直すのが本筋。
- プールは全レース一定（レースごとの売上を列で渡せば対応可能）。他の購入者の動きは確定オッズに含まれる分だけ考慮。
- 購入するかどうかの判断には自分の影響を入れていない（影響を見込んで EV<しきい値になる馬を見送る、額を `optimal_stake` で決める、は未実装）。
- 同着の払戻按分は従来どおり無視。複勝・他券種は未対応（複勝は払戻の計算方法が違う）。

# 頑健性の検証: 市場が効率的になるとエッジはどう縮むか

> ⚠️ **このページの数値はすべてシミュレーター (`banei_ai/simulate.py`) の人工データ上のものです。**
> 実際のばんえい競馬の成績ではなく、実馬券での収益性について何も保証しません。

## 目的

1. **パイプラインが「エッジ」をでっち上げないか** (帰無仮説の検定): 歪みのない市場でモデルが市場に勝ったように
   見えるなら、リーク・較正・選択バイアスのどこかに問題がある。
2. **市場の歪みが小さくなるにつれて、検出されるエッジがどう縮むか**: どの程度の歪みなら検出でき、
   どの程度なら控除率 (20%) を越えて儲かるのか。

## 方法

### 市場の設定 (`SimConfig`)

| 設定 | 内容 |
|---|---|
| `distortion = s` (0〜1) | 埋め込んだ 5 種類の歪み (大穴の過剰人気、人気騎手の過大評価、前走着順への過剰反応、馬場水分適性の無視、馬体重大幅減の軽視) をまとめて s 倍する。**s = 1 が従来の既定** (README の数値)。個別には `d_flb` などで調整できる |
| `preset("efficient")` | **帰無仮説**。歪み 0、市場は真の強さ (モデルが見られない調教の気配なども含む) を完全に知り (`market_info_sd = 0`)、第2障害での停止の偶然まで織り込んだ真の勝率そのもので値付けする (`market_stop_aware`)。どの馬の真の期待値も ≈ 0.8 (控除 20%)。モデルの特徴量はすべて真の強さの粗い代理なので、市場に足せる情報は原理的にゼロ |
| `preset("realistic")` | 実データの統計 (L1 調査: 単勝払戻率 80%、人気別の勝率・回収率、平均配当 661 円、1 日 11R、最大 10 頭) に合わせた中間設定。大穴の過剰人気 `d_flb = 0.5`、他の歪みは実データで未測定のため 0.25 (暫定) |

注意点:

- **s = 0 でも市場は完全には効率的でない。** 既定の市場は真の強さを誤差 (`market_info_sd = 0.2`) 付きで見ており、
  この誤差を公開情報 (近走成績) で補正していない。モデルは近走成績からこの誤差の一部を正当に拾える
  (下の表で s = 0 の Δ対数損失が +0.009)。これは「歪み」ではなく市場の情報不足で、帰無仮説には使えない。
  そのため帰無仮説は別に `efficient` を用意した。
- **共通乱数**: 同じ seed なら s を変えてもレース結果 (着順・タイム) は完全に同じで、オッズだけが変わる。
  s の違いによる差は市場の違いだけで生じる。その代わり、seed ごとの「運」(どの穴馬が勝ったか) は全ての s に共通して現れる。
- **真の期待値**: シミュレーションでは真の勝率が分かる (`simulate.true_win_probs`、停止の偶然まで含めた厳密な計算)。
  買った馬の「真の勝率 × オッズ」の平均が 1 を超えて初めて、本物のエッジと言える。
  **実現回収率は運に大きく左右される**ので、エッジが本物かどうかはこちらで判断する。
- 「モデルの見積もり」は買った馬の `p_model × オッズ` の平均 (モデル自身が思っている期待値)。

### 手順

`build_features` → `walk_forward` (2 か月ブロックの完全サンプル外) → `evaluate_probs` (Δ対数損失 = 市場の対数損失 − 合成モデルの対数損失、正ならモデルが良い)
→ `BetRule(min_ev=1.10)` の均等買い → `bootstrap_roi` (レース単位, 90%区間) → `split_half_check` (前半で選んだしきい値を後半に適用)。

```bash
# 歪み {0, .25, .5, 1} × seed {42, 3, 7} + efficient (2023-04〜2025-09, サンプル外 約 1,890 レース/シード)
OMP_NUM_THREADS=1 python scripts/robustness.py
OMP_NUM_THREADS=1 python scripts/robustness.py --scales realistic
# 帰無仮説を多くのシードで (テストと同じ期間, 約 836 レース/シード)
OMP_NUM_THREADS=1 python scripts/robustness.py --scales efficient --seeds 3,42,7,11,5,1,101,102,103,104,105,106 \
    --start 2023-04-01 --end 2024-12-31
```

1 回 (2.5 年分) あたり 1 コアで約 50 秒。特徴量と予測は `data/interim/robustness/` に保存して再利用する。

(11 勝、真の期待 5.4 勝。真の確率の下でこれ以上になる確率は約 3%)。seed 42 は 13 点で 232%、seed 104 は 6 点で 290%。

(p_model / p_mkt ≥ 1.4 の 226 頭) では実現回収率 75% で、真の 80% と整合する。

## 解釈

### 1. 偽陽性 (s = efficient)
パイプラインは効率的な市場で情報をでっち上げない。Δ対数損失はゼロ以下、買った馬の真の期待値は払戻率どおり 0.80、
リーク検査もゼロ。**ただしモデルの期待値の見積もりは 1.18 で、実現回収率も運次第で 160% 台になる。**
「期待値 ≥ 1.1 で買って回収率が 100% を超えた」だけでは、エッジの証拠にならない。

### 2. 検出しきい値
- **対数損失 (情報の有無)**: Δ対数損失は歪みの大きさにほぼ**二乗で**増える (概ね 0.009 + 0.02·s²。
  市場の誤差が勝率の対数に効くため、改善余地は誤差の二乗に比例する)。s = 0.25 では s = 0 (市場の測定誤差だけ) と
  区別できず、s = 0.5 で +0.004 (3 シードとも s = 0 を上回る)、s = 1 で +0.020 上乗せされる。
  1 シード (約 1,900 レース) の標準誤差は 0.002〜0.003 程度なので、**埋め込んだ歪みは s ≈ 0.5 前後から検出でき、
  s = 0.25 では検出できない**。モデルが取れているのは「真の確率 vs 市場」(改善の上限) の 11〜19% にすぎない。
- **儲かるか (控除 20% を越えるか)**: 期待値 ≥ 1.1 で買った馬の真の期待値は、s = 0〜0.5 では 0.99〜1.02 (トントン)、
  s = 1 で初めて 1.15。**情報としてのエッジは見えても、控除と選択バイアスを越えて儲かるのは歪みが既定の半分を
  大きく超えてから**。既定 (s = 1) の歪みはかなり大きい設定 (市場が真の確率より対数損失で 0.15 悪い)。

### 3. 回収率と歪みの関係
- 真の期待値は 0.80 (efficient) → ≈1.00 (s = 0〜0.5) → 1.15 (s = 1) と非線形に増える。
- 実現回収率 (107〜122%) は s とほとんど連動せず、運に支配されている。例: s = 0.5 の seed 3 は 137% (区間 105〜171%) だが
  真の期待値は 0.99。s = 0 の seed 7 は 33% だが真の期待値は 1.07。
- **回収率の区間の下限 > 100% が、真の期待値 ≈ 1.00 で 2 回出た** (s = 0 と s = 0.5 の seed 3)。共通乱数のため
  同じ seed の運はすべての s に持ち越される。区間の下限は「片側 5% の検定」1 回分でしかなく、しきい値や期間を
  何通りも見れば偽陽性は増える。
- 前後半検証 (前半で選んだしきい値を後半に適用) も、後半の点数が少ないと 0%〜200% 超まで振れる。
- モデルの期待値の見積もりは s によらず 1.14〜1.22 でほぼ一定。**見積もりの大きさからは本物かどうか判別できない**。

### 4. realistic (実データの統計に合わせた設定)
Δ対数損失は +0.016 だが、較正後の市場との差は +0.006 (大半は大穴の過剰人気を較正し直した分)。
買った馬の真の期待値は 1.06 で、3 シードとも回収率の区間は 1 をまたぐ。実際の市場が realistic 程度なら、
**エッジはあっても小さく、2〜3 年分のデータの実現回収率では本物かどうか判定しにくい**。
(realistic の騎手人気などの歪みの大きさは仮定であり、実データでは未確認)

## 実データで判断するときの指針

1. **合成モデルの Δ対数損失 (vs 較正後の市場) を第一の指標にする。** 回収率より運に左右されにくい。
   約 2,000 レースで標準誤差 0.002〜0.003 程度なので、+0.006 を超えて初めて「情報がある」と言える目安
   (帰無テストのしきい値と同じ)。
2. **回収率の区間の下限 > 1 は単独では信用しない。** 効率的な市場でも合算 85 点で 166% が出た。
   前後半・複数の期間・複数のしきい値で一貫して勝っているか、点数が数百点以上あるかを確認する。
3. **モデルが思っている期待値は割り引く。** 効率的な市場では 1.18 と思って買った馬が実際は 0.80。
   `min_ev` を上げても選択バイアスは消えない (むしろ強まる)。
4. 実際の市場が既定 (s = 1) ほど歪んでいる可能性は低い。README のシミュレーション回収率 125% は上限の目安。

## 制約

- 市場モデルは単純 (強さの softmax にべき乗の歪みを掛けるだけ)。実際の市場には締切直前のオッズ変動、
  自分の購入によるオッズ低下 (プールが小さい) などもある。
- 歪みは既知の形で埋め込んでいるので、モデルがそれを捉えやすい形の特徴量を持っている (実データより有利)。
- realistic の較正は L1 の調査 (検索結果の抜粋ベースで未検証) による。平均頭数・騎手人気などの歪みの大きさは未確認。
- シード数は帰無仮説 12、歪み別 3。歪み別の Δ対数損失の差は 0.003 程度の誤差を含む。
